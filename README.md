# 唐人街

这是《唐人街》私友局手机网页游戏原型，支持 3-4 人创建房间、加入房间、地块/店铺发放、放置店铺、交易、收入结算和最终排名。

## 本地启动

安装依赖：

```bash
npm install
```

启动本地服务器：

```bash
PORT=4174 npm run dev
```

电脑打开：

```text
http://127.0.0.1:4174/
```

手机和电脑连同一个 Wi-Fi 后，打开启动日志里显示的局域网地址。

## 测试辅助模式

开发时可以打开：

```text
http://127.0.0.1:4174/?test=1
```

页面左下角会出现测试按钮，可以快速补满玩家、跳轮次、发店铺和跑规则自检。

## Docker 部署

先准备环境变量：

```bash
cp .env.example .env
```

启动容器：

```bash
docker compose up -d --build
```

查看服务是否正常：

```bash
curl http://127.0.0.1:4174/api/health
```

停止服务：

```bash
docker compose down
```

## 服务器上线建议

推荐先部署为朋友内测服，不要直接当正式公开服务。

最低要求：

- 服务器安装 Node.js 20 或 Docker
- 对外开放 HTTP/HTTPS 访问
- 如果使用反向代理，需要支持 WebSocket
- 建议使用 HTTPS

重要限制：

- 当前房间和游戏进度保存在服务器内存里
- 服务器重启、容器重启或部署更新后，正在玩的房间会丢失
- 之后如果要更稳定，需要加数据库或存档机制

## 常用接口

健康检查：

```text
/api/health
```

查看本机和局域网访问地址：

```text
/api/network-info
```
