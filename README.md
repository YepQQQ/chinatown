# 霓虹唐埠

这是《唐人街》私友局手机网页游戏的 P0 原型。

当前目标很小：先在手机浏览器里跑通本地原型流程，包括创建/加入房间、等待室、锁定 3/4 人局、进入主游戏界面、85 格地图、玩家状态、地块手牌、商铺栏和地块摘要。

## 怎么打开

先安装依赖：

```bash
npm install
```

再启动本地联机服务器：

```bash
npm run dev
```

然后用浏览器打开：

```text
http://127.0.0.1:4173/
```

同一局里的朋友需要打开同一个地址，并输入房主页面上的房间码加入。

## 开发测试模式

如果只是自己测试后续流程，可以直接打开：

```text
http://127.0.0.1:4173/?dev=1
```

它会自动创建一个 3 人局并跳过房间等待，直接播放先手转盘、开局资金入账，然后进入第 1 轮候选建筑卡阶段。

## 当前还没有做的事

- 选择并确认保留的建筑卡
- 抽取并展示商铺砖
- 后续轮次发牌、交易、建设、收入结算
- image2 生成的正式美术图

这些会按步骤逐个补上。
